《皮套之下》stage0–stage4 原型

Unity 6000.3.21f1 / C#。支持狗仔 + AI 主播、主播 + AI 狗仔，以及两台 Windows 电脑局域网双人对战。

启动
1. 打开 Assets/UnderAvatar/Scenes/UnderAvatarPrototype.unity。
   测试默认自动展开 Game 视图，停止后恢复；可在编辑器关闭“测试时展开 Game 视图”。
   HUD 显示当前角色所在层和主播电脑所在层；默认电脑在二楼，主播会在各层巡逻。
2. 不要点 Play。打开 Tools > Under Avatar > Level Editor，在房屋编辑器窗口中制作关卡。
3. 关卡资源默认位于 Assets/UnderAvatar/Levels/DefaultBuilding.asset；点击“保存关卡资源”保存。
4. 在编辑器修改 Flappy Bird 通关分数，默认 15。角色在 Play 后的启动界面选择。
5. 点 Unity Play 或“Play 测试当前关卡”，选择狗仔 / 主播单人测试，或创建 / 加入局域网房间。Esc 返回角色选择。
6. 停止 Play 后继续编辑；运行时使用关卡副本，测试不会改写关卡资源。
如果在另一份工程复制这些脚本，请先执行 Tools > Under Avatar > Prepare Prototype，生成碰撞层和默认资源。

角色外观
- Tools > Under Avatar > Character Models，可分别替换狗仔 / 主播 Prefab，调整模型位置、朝向、缩放、动画参数和网络外观平滑。
- 默认狗仔使用“你豆姐”（待机、行走、静步、蹲下 / 蹲行骨骼动画），主播使用“恐怖奶龙”（静态模型）。
- 完整接入说明见 Assets/UnderAvatar/角色模型与联机动画说明.txt；替换模型后重新开始测试，两台电脑使用同一版资源。

场景外观
- 墙、绿墙裙、地砖、天花板、水泥楼梯与锈铁栏板使用参考图风格贴图。
- Tools > Under Avatar > Building Surface Materials 可替换材质、调整纹理米数与墙裙高度比例；详见“建筑材质说明.txt”。
- 床、衣柜、电脑桌、门扇与桌子已接入 Assets/Models 提供的模型，正式关卡和大厅共用。
- Tools > Under Avatar > Level Object Catalog 可调整预制体、位置、朝向和缩放；详见“场景模型替换说明.txt”。
- 床按要求使用原模型；床和柜子保留交互反馈，暂不拆分开合部件。

局域网双人对战
1. 两台电脑接入同一局域网，使用相同版本。可一台使用 Unity Play，另一台运行 Windows 版。
2. 房主在启动界面选择自己的角色，点击“创建房间”。默认 TCP 端口 7777，可修改。
3. 另一位玩家输入房间里显示的房主 IPv4 和相同端口，点击“加入房间”，自动使用另一角色。
   127.0.0.1 仅用于同一台电脑开两个进程，另一台电脑须填写房主的局域网 IP。
4. 关卡和玩法参数自动从房主同步，不覆盖加入者的编辑资源。双方点击“我已准备”，房主点击“进入教学大厅”。
   大厅正常照明，仅练习物体交互，不运行小游戏、计时或胜负。按 Tab 再次准备，双方准备后由房主开始正式对局。
5. 主播从电脑前开播，Flappy Bird 15 分通关后搜捕；狗仔每场直播只能提交一张主播照片，物证不限。
6. 本机移动、转头和拍翅立即响应；客户端预测碰撞，并按房主确认的输入序号校正。门、衣柜、取证、通关和胜负仍由房主判定。
   联机时不使用 AI，禁用调试参数和 AI 观察窗。左上角显示本机 FPS、房主 FPS 和网络往返延迟，便于区分掉帧和网络延迟。
7. 对局结束可返回房间，重新准备再开一局。离开、断线或连接超时会返回选择界面并说明原因。
8. 如果 Windows 首次询问网络访问，请允许游戏在“专用网络”通信；连接失败时核对 IP、端口和同网段。

Windows 可运行版本
- 当前联机协议 v8，加入任务编辑器、手机选任务/拍照/手动上传、可搬运道具与目标区域；支持教学大厅和正式对局。两台电脑必须一起更新，不能与旧版本混用。
- 构建入口：Tools > Under Avatar > Build LAN Windows Player。
- 输出：Builds/UnderAvatarLAN/UnderAvatar.exe。复制整个 UnderAvatarLAN 文件夹到另一台电脑，不能只复制 exe。
- 不依赖账号、互联网服务器或第三方联网包。当前是两人局域网原型，不含互联网中继、房主迁移或中途重连。

编辑器
- 在窗口启用“网格摆放”，到 Scene 视图左键放置 / 选中，右键删除，R 旋转 90 度。
- 关闭摆放或按 Esc 后，选择场景物品，W / E 手柄移动或旋转，吸附到网格和 90 度。
- 视图使用 Unity 原生操作，Alt + 鼠标仍可调整视角；“聚焦当前楼层”找回地图。
- Ctrl+Z 撤销，Ctrl+Y 重做；选中物品属性在房屋编辑器窗口中修改。
- 支持 1–12 层，当前层以上隐藏，下层物体暗显。删除楼层会重新编号。
- 任务物品放置后自动聚焦窗口内的任务属性。Quest ID 必须唯一，描述不能为空。
- 家具可选择衣柜或桌子。衣柜可以躲藏。
- 折返楼梯只放在下层，占两列网格，包含两段真实台阶、中间平台和扶栏；自动在上一层开洞。直接步行上下，不再按 E 传送。
- “统一建筑尺寸”可修改全部墙高、层高及楼层宽深。楼梯高度随墙高变化；长度根据台阶坡度增长，空间不足会提示。
- 每层始终生成带碰撞的地板，新建楼层立即显示地板。楼梯及洞口的占地不能与物品重叠。
- JSON 导入/导出使用 Unity 文件对话框；无效导入不会修改关卡。支持另存为新 Building 资源。
- Scene 中的房屋为自动生成的预览，保存内容以 Building 资源为准。请通过编辑器工具操作物品。
- 默认地图：2 层、4 扇门、1 个电脑桌、3 个任务物品、折返楼梯与衣柜。
- 游玩模式要求恰好一个电脑桌，且出生区域能通过门/楼梯抵达电脑。

狗仔操作
- WASD 普通行走会发出脚步声；按住 Shift 静步，速度 ×0.45 且无脚步声。没有快跑。
- 按住 Ctrl 蹲下，松开站起；蹲行 ×0.45 且静音。视角与碰撞体同步降低，头顶被挡时不能站起。
- 鼠标观察，E 操作门 / 衣柜；沿楼梯走到上层平台即可上楼。
- F 打开手机，先选择任务，点击进入相机或按 Q 取景；左键/空格拍照，预览后手动上传，或取消照片。
- 绿色取景框表示至少有一个未完成且可提交的目标。
- 拍照要求目标在框内、距离严格小于上限，且没有墙、关闭的门或家具遮挡。
- 一张照片可以同时完成多个有效目标；没有新目标则扣 1 分。
- 每场直播最多拍一张有效主播照片；取消不会恢复本场额度。任务物品照片不限次。只有错误上传才扣一次失误次数，单纯拍照或取消不扣分，重复点击同一照片上传不会重复结算。
- 碰撞重试、等待或猛回头都不恢复本场主播照片额度；要等主播通关后的下一场直播。
- 拍齐地图物证和 3 张直播照片获胜；失误次数耗尽或被主播抓到则失败。
- 躲入衣柜后不会被主播发现，且不能使用手机。E 离开。

主播和小游戏
- AI 使用近距离视野及脚步、门声、快门声线索搜索，不会持续读取隐藏玩家的位置来追踪。
- 默认搜捕 30 秒后实际寻路返回电脑，自动开门并实际行走折返楼梯。
- 直播小游戏为 Flappy Bird：空格 / 左键拍翅，每通过一根管道得 1 分；默认 15 分通关。
- 碰撞或掉出画面会清零分数，按空格 / 左键重试；仍处于直播锁定中，不能移动、回头或抓捕。
- AI 主播同样通过拍翅、避开管道达到目标分数，没有计时自动通关。
- 真人主播通关后使用 WASD / 鼠标搜捕，靠近狗仔自动抓捕，E 操作门或在电脑前重新开播。
- 搜捕时间结束后提示回电脑，返程时不能抓捕；人类玩家须自行走回并按 E。
- AI 狗仔通过真实门和楼梯收集物证、每场直播偷拍一次；遇到视野内的主播会逃跑或藏入衣柜。
- 双方在纯黑环境中使用真实聚光灯，墙、门和家具投射阴影，亮度随距离与光锥边缘自然衰减；双方都能看到对方照亮的物体。
- 主播默认距离 6.5 米、内/外角 10°/45°；狗仔 12 米、20°/75°。转头仅灯光有轻微滞后，鼠标视角即时响应。
- Tools > Under Avatar > Level Editor > 视野与照明：分别调节双方的距离、内外角、亮度、转向跟随时间和 Cookie 强度。参数保存在场景中，修改后 Ctrl+S；联机使用房主参数。
- Cookie 为程序生成的羽化微噪声光斑，强度 0 关闭；跟随时间 0 立即对齐。灯光距离是衰减终点，不保证整个范围内亮度一致，也不限制观察对方照亮的区域。
- 狗仔躲入衣柜后关闭自己的灯光，离开时恢复；主播观察窗使用同一套真实照明。声波提示保留，只有当前角色启用 AudioListener。
- 达到本场目标分数才恢复搜捕；仅等待不能解锁。
- 狗仔模式左上角观察窗仅用于原型调试，显示主播的有限视野和穿墙声波（包括来源楼层）。
- 玩家自己听见的是空间音效；观察窗不会改变狗仔的相机遮挡规则。

stage4 / 调试
- 每次快门都有声音与 0.3 秒闪光；拍到直播中的主播会使观察窗震动并显示警告。
- Tab 打开/折叠调试面板并释放/捕获鼠标；面板打开时 AI 仍在运行。
- 滑块：双方移速、拍照距离、容错上限、Flappy Bird 目标分数。目标分数在下一场开播时生效。
- AI 主播的实验“猛回头”默认关闭；真人主播测试禁用此例外。开启后为 0.6 秒前摇、3 秒抓捕窗口；扑空会清零进度并眩晕 3 秒，然后返回电脑重新挑战。
- 可以关闭 AI 观察窗，避免调试信息影响狗仔体验。

代码入口
- BuildingData / BuildingWorld：序列化数据、地图实例、碰撞体。
- BuildingAsset：持久化关卡资源；BuildingEditorWindow / Model / Preview：Unity 原生编辑、撤销与场景预览。
- PrototypeApp / PrototypeHud：启动当前关卡和游戏 HUD。
- MatchSession / ReporterController：拍照、任务、移动交互及胜负。
- BuildingNavigation / StreamerController：跨楼层导航和主播状态机。
- IStreamerDriver / AiStreamerDriver：单人测试中的 AI 主播。
- LanGame / LanTransport / LanProtocol：房间、TCP 消息帧、准备/加载握手、输入与权威状态同步。
- ClientPrediction：每帧鼠标响应、60 Hz 本地输入预测、按确认序号重演未确认输入与小幅校正的视觉平滑。
- MinigameLevel：Flappy Bird 飞行、管道、碰撞与得分模拟；人类 / AI 共用。
- AiReporterDriver：AI 狗仔取证、躲避和物理寻路；CharacterPosture：蹲下与站起净空检查。

验证
Unity Test Runner：UnderAvatar.EditModeTests 和 UnderAvatar.PlayModeTests。
覆盖原生编辑撤销/重做、资源与 JSON 保存、运行副本隔离、楼层编辑、物理楼梯、门遮挡、照片跨场次限额、胜负、Flappy Bird 碰撞与通关、蹲下净空、脚步静音、主播视角和 AI 狗仔取证。
大厅验证记录与截图位于 Builds/HallVerification，其余近期验证见 Builds 中相应 Verification 目录。
目前使用程序化灰盒场景，角色为你豆姐与恐怖奶龙；行走、搜捕、门、喘气和快门已采用剪辑后的 CC0 实录素材。

音效替换
Tools > Under Avatar > Audio Settings，或房屋编辑器的“音效配置 / 替换声音”。
配置资源：Assets/UnderAvatar/Resources/GameAudio.asset。拖入 AudioClip 即可替换，支持各类音量、步频、音高变化与空间衰减距离。
狗仔移动时仅本机播放喘气，Shift / Ctrl 时更轻；喘气不广播、不产生声波、不触发 AI 听觉。
普通走路有脚步声；静步与蹲行仍无脚步声；主播搜捕使用独立脚步录音，没有恢复快跑功能。
配置说明与来源许可：Assets/UnderAvatar/Audio/使用说明.txt、SOURCES.txt。
音效验证记录：Builds/AudioVerification。原有椅子与成功提示音可在配置中替换，留空保持合成提示音。

本次玩法与编辑器调整
完整操作见同目录“关卡与直播调整说明.txt”。物体库入口：Tools > Under Avatar > Level Object Catalog。
狗仔可藏衣柜或床；主播按 E 搜查才能抓到隐藏者，搜错分别扣 5 / 12 秒，每个藏身点每轮只扣一次。
返程开播宽限 10 秒，之后每 10 秒扣 1000 粉丝，默认初始 5000；粉丝归零主播失败。
房屋编辑器可设置每场直播分数、统一小游戏物理参数、自定义命名物体及预制体外观。
主播界面：顶部计分与粉丝、左侧 Flappy Bird、右侧循环滚动弹幕、底部操作提示。

AI 对战新手教程
- 单人选择主播或狗仔后，先进入与联机相同的明亮教学大厅，自由练习门、床、衣柜、手机与楼梯。
- 按 Tab 打开大厅菜单，点击“准备进入对局”，再点击“开始正式 AI 对战”；可取消准备，没有倒计时。
- 大厅不运行对战 AI、小游戏、计分或胜负；另一角色留在大厅，不干扰练习。
- 正式对局加载当前配置的正式关卡及玩法参数，重新初始化角色、门、藏身状态、手机、证据、粉丝和小游戏；恢复黑暗照明与 AI 对手。
- 正式关卡不显示大厅教程说明牌。结束后“返回大厅再来一局”重新经过准备流程，返回角色选择也会清空准备状态。

任务编辑器：Tools > Under Avatar > Task Editor。详细步骤见“任务编辑器使用说明.txt”。示例关卡为 Assets/UnderAvatar/Levels/TaskEditorExample.asset，可在房屋编辑器的关卡资源中选择。
