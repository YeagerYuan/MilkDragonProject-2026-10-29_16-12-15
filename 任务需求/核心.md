- # Role & Task
  你是一个资深 Unity URP 渲染与 Shader 工程师。我正在开发一款中国 80-90 年代背景的室内恐怖游戏（Unity URP 管线，狗仔偷拍题材）。
  当前的**最高视觉优先级**是实现类似《Content Warning》及复古伪纪录片的**“DV 摄像机低清模糊 + 色阶断层（Posterization）+ 手电筒强过曝”**画面风格，并结合阴暗潮湿的室内环境光影。

  请帮我编写一套完整的 Shader 与 C# 脚本（包含 Editor 一键配置工具和 Runtime 脚本），确保所有代码可直接编译运行（使用 `UnityEngine.Rendering` 和 `UnityEngine.Rendering.Universal` 命名空间）。

  # Deliverables Required
  请生成以下 4 个核心文件：

  ## 1. `Assets/Shaders/DV_Camcorder_Blur.shader`（最高优先级：DV 低清模糊与色阶量化 Shader）
  编写一个兼容 Unity URP UI `RawImage`（及 Blit 通用）的全屏后处理 Shader，严格按以下管线顺序处理画面：
  1. **双线性降采样与柔和模糊（Downsampling & Soft Blur）**：
     - 属性 `_TargetResolution` (Vector2, 默认 `520, 292`)：将输入 UV 按目标低分辨率对齐采样。
     - 属性 `_BlurRadius` (Range 0~3, 默认 `1.25`)：在低分辨率网格基础上进行 5-tap 或 9-tap 邻域平滑混合，产生老式便携摄像机焦距不准的“肉感模糊与边缘涂抹感”（拒绝锐利的马赛克像素块）。
  2. **横向色差溢散（VHS Chroma Bleed）**：
     - 属性 `_ChromaOffset` (Range 0~0.02, 默认 `0.0045`)：对 R 通道和 B 通道在水平（X 轴）方向进行轻微偏移采样与尾迹混合，还原磁带信号模糊的红蓝紫边。
  3. **手电筒高光强过曝与色阶断层（Overexposure & Posterization）**：
     - 属性 `_Overexposure` (Range 1~3, 默认 `1.45`)：对高亮度区域进行非线性放大，让靠近手电筒中心的人物皮肤与浅色墙面直接过曝成惨白色。
     - 属性 `_ColorSteps` (Range 4~64, 默认 `14.0`)：对颜色或明度（Luminance）执行离散量化 `floor(col * _ColorSteps) / _ColorSteps`，使手电筒光圈在墙面上形成一圈圈明显的明暗色带断层（Color Banding）。
  4. **暗部磁带底噪与强暗角（Tape Noise & Vignette）**：
     - 属性 `_NoiseIntensity` (Range 0~0.2, 默认 `0.05`)：基于 `_Time.y` 在暗部叠加动态颗粒噪点。
     - 属性 `_VignetteIntensity` (Range 0~1, 默认 `0.55`)：强力压黑画面四周边缘。

  ## 2. `Assets/Runtime/DVCamcorderDisplay.cs`（低分辨率渲染管线与 OSD 界面驱动）
  创建一个挂载在 `Main Camera` 上的运行时组件，提供 `SetupCameraPipeline()` 方法并在 `Awake()` 中校验：
  - **低清 RenderTexture 模糊映射**：
    - 创建一个分辨率为 `520 x 292` 的 `RenderTexture`（`filterMode = FilterMode.Bilinear`，`antiAliasing = 1`），确保利用硬件双线性插值拉伸产生天然模糊感。
      -为了避免主相机直接赋 `targetTexture` 导致屏幕无输出，采用 **子相机渲染到 RT + 主相机只渲染 UI 层**（或通过 `OnRenderImage` / `RenderPipelineManager.endCameraRendering` 抓取画面）的稳健结构：
      - 在场景中自动构建一个 `Screen Space - Overlay` 的全屏 `Canvas (DV_Monitor_Canvas)`，排序层级最高。
      - 底层创建全屏 `RawImage`，挂载使用 `DV_Camcorder_Blur.shader` 的材质球并显示低清 `RenderTexture`。
  - **复古摄像机 OSD 界面生成**：
    - 在该 Canvas 四角自动生成带轻微模糊重影的 UI 元素（使用 TextMeshPro 或 Text）：
      - 左上角：灰粉色/半透明白色粗体 `CAM` 字样。
      - 左下角：实时走动的复古时间戳 `PM 05:20`（随游戏时间跳动）。
      - 右上角：预留相机图标与播放三角箭头指示器 `[O] ►`。
      - 右下角：`[Tv]` 标识。

  ## 3. `Assets/Editor/HorrorSceneSetupWindow.cs`（一键环境、后处理与 DV 滤镜配置工具）
  创建菜单项 `Tools/Horror Setup/1. Initialize DV Blurry Atmosphere & Post-Processing`，点击后自动执行：
  - **环境光与天空盒重置（冷蓝暗部底色）**：
    - 将 `RenderSettings.skybox` 设为 `null`。
    - 将 `RenderSettings.ambientMode` 设为 `AmbientMode.Flat`。
    - 将 `RenderSettings.ambientLight` 设为幽暗的冷蓝灰色 `new Color(0.045f, 0.06f, 0.10f, 1f)`，让手电筒未照到的远处房间保留微弱的深蓝轮廓感。
    - 查找场景中的 `Directional Light` 并将其禁用。
  - **指数雾效（Fog）配置**：
    - 开启 `RenderSettings.fog = true`，模式为 `FogMode.ExponentialSquared`。
    - 颜色设为 `new Color(0.02f, 0.03f, 0.05f, 1f)`，浓度 `fogDensity = 0.045f`。
  - **全局后处理（Global Volume）生成（配合 DV 过曝与褪色）**：
    - 创建 `Global Volume_Horror`（`isGlobal = true`），并在 `Assets/Settings/` 下创建保存 `VolumeProfile`：
      1. `Tonemapping`：Mode = `TonemappingMode.Neutral`（严禁使用 ACES，保留手电筒中心高光过曝张力）。
      2. `ColorAdjustments`：Post Exposure = `0.15f`，Contrast = `28f`，Saturation = `-25f`（高对比褪色感）。
      3. `LiftGammaGain`：Lift 往冷蓝偏移 `new Vector4(0.94f, 0.96f, 1.04f, -0.01f)`，Gain（高光）往暖黄偏移 `new Vector4(1.05f, 1.0f, 0.90f, 0.05f)`，拉大冷暖撞色。
      4. `Bloom`：Threshold = `0.85f`，Intensity = `0.85f`，Scatter = `0.75f`（强化手电筒照射在人物脸上的白色光晕溢散）。
  - **自动挂载手电筒与 DV 滤镜**：
    - 自动在 `Main Camera` 上挂载 `DVCamcorderDisplay` 与 `HorrorFlashlightController` 并完成初始化。

  ## 4. `Assets/Runtime/HorrorFlashlightController.cs` 与 `Assets/Editor/HorrorPBRMaterialAutoLinker.cs`

    - `BounceHalo`（外围散射光）：Spot Light，Range = `7f`，Spot Angle = `85f`，Intensity = `0.6f`，无阴影。

  - **`HorrorPBRMaterialAutoLinker.cs`（适配低清模糊的 PBR 材质批量组装工具）**：
