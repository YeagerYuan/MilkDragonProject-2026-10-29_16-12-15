# 皮套之下 · Unity 双人恐怖原型

第一人称主播与狗仔对抗原型，支持局域网双人对战及两种角色的 AI 测试。当前联机协议为 **v17**，两端使用相同版本和资源。

## 打开项目

- Unity：**6000.3.21f1**，项目使用 URP 与 Input System。
- 先安装 Git LFS，再克隆仓库。模型、贴图、录音等资源通过 Git LFS 管理。

```powershell
git lfs install
git clone https://github.com/YeagerYuan/MilkDragonProject-2026-10-29_16-12-15.git
cd MilkDragonProject-2026-10-29_16-12-15
# 如果更新内容仍在合并请求中，切换到对应分支：
git switch codex/integrate-furniture-20261104
git lfs pull
```

在 Unity Hub 中添加项目根目录，打开 `Assets/UnderAvatar/Scenes/UnderAvatarPrototype.unity`，等待资源导入与脚本编译。

Tripo Bridge 是可选的模型导入工具，不属于运行游戏的依赖。共享 Packages 配置不包含任何开发者机器的绝对路径；需要使用该工具时，在 Package Manager 中从本机磁盘安装其 `package.json`。

## 编辑与试玩

- 房屋编辑器：`Tools > Under Avatar > Level Editor`。
- 任务编辑器：`Tools > Under Avatar > Task Editor`，也可从房屋编辑器进入。
- 装饰物自由摆放：`Tools > Under Avatar > Free Placement`，支持柜顶、桌面等非网格位置，不会自动生成任务或拿取行为。
- 任务目标可以绑定可阅读文档、主播、电脑，以及同一张照片内的多个物体。“额外直播证据”可按关卡配置，更新后的默认关卡使用手机任务作为通关目标。
- 物体库增加家具模型和碰撞尺寸设置。同位置、同旋转的楼梯可逐层堆叠，连接更多楼层。
- 旧关卡首次使用任务编辑器时，点击“启用任务编辑并导入现有任务”。
- 示例：在房屋编辑器的“关卡资源”中选择 `Assets/UnderAvatar/Levels/TaskEditorExample.asset`，体验拍摄苹果和把小球搬到特殊桌子上再拍照的任务。
- Play 后选择任一角色进入 AI 教学大厅，准备后开始正式对局。局域网模式由房主选择角色，另一台输入房主 IP 加入；双方在教学大厅再次准备后，由房主开始正式对局。

`WASD` 行走，`Shift` 静步，按住 `Ctrl` 蹲下，`E` 交互或拿起/放下道具。`F` 打开手机，选任务后进入相机；`Q` 切换手机菜单和取景，左键/空格拍照，预览后手动上传。拍照和取消不扣分，仅错误上传扣一次失误次数。

`Esc` 打开设置，支持总音量、无边框全屏、继续、返回主菜单和退出游戏；音量与全屏选项保存在本机。文档和手机界面中先收起当前界面。单人设置会暂停对局，联机设置不暂停其他玩家，只停止本机操作。

打包程序支持 `F11` 或 `Alt+Enter` 切换全屏/窗口，也可在设置里勾选“无边框全屏”。首次运行默认全屏；切换保持启动时的渲染分辨率（默认 `960×540`），全屏铺满显示器，双角色 DV 的内部低清分辨率与模糊参数保持原值。Unity 编辑器的 Game 视图不执行系统窗口切换。

联机使用非阻塞 TCP 与房主权威判定。客机的移动、转头、蹲下和拍翅在本地即时预测，输入以 60 Hz 模拟并合批发送，状态以 20 Hz 同步；较大消息压缩，未发送的旧状态合并为最新状态，交互和音效事件保持可靠顺序。每帧限制收发与校正工作，长时间积压时优先保持本机操作响应。网络差仍会延迟对方动作及交互确认，恢复后与房主校正；连续 30 秒无响应则断开。

正式对局保留 DV 复古渲染，教学大厅保持原有照明。从 `Tools > Under Avatar > DV Rendering` 打开“双角色画质”，分别调整狗仔和主播的模糊半径、画面分辨率及色散，也可从房屋编辑器的“画质 / 狗仔与主播模糊效果”按钮进入。Play 时修改可实时预览，点击保存按钮写入资源。

狗仔材质为 `Assets/Settings/Resources/HorrorDVSignal_Reporter.mat`，主播材质为同目录 `HorrorDVSignal_Streamer.mat`，AI 主播观察窗也使用主播材质。模糊半径越大越模糊，画面分辨率越低越低清；半径 0 关闭额外柔化，仍保留低分辨率与其他复古效果。可从默认 `520×292 / 1.25` 起调，较清晰可尝试 `960×540 / 0.3`。旧 `HorrorDVSignal.mat` 保留为通用初始模板。后处理在同目录 `HorrorDVVolume.asset` 调整。默认正式场景的 Flappy Bird 通关分数保留为 12 分，可从房屋编辑器的玩法设置中修改。

## 狗仔开场漫画

单人选择狗仔后、联机双方准备进入教学大厅时，狗仔每次都会先看漫画；主播直接进入原有流程。点击依次显示五幕，淡入过程中点击会直接完成当前幕，第五幕显示完再点击进入大厅。右上角“跳过”可直接进入。联机阅读期间仍发送心跳；完成后继续大厅加载，断线会取消尚未执行的跳转。大厅准备后进入正式对局不重复播放。

原图及自动裁切图片在 `Assets/UnderAvatar/Art/Comics/Paparazzi`，`Layout.json` 记录原图左上角像素区域和 1920×1080 画布中心坐标、尺寸。左页底排的两个小格一起作为第三幕。`Background.png` 仅保留纸张、书脊和页码，不会提前露出剧情。

打开 `Tools > Under Avatar > Comic Builder`，拖入同样为“左三排、右两排”的漫画原图，点击“自动切图并生成预制体”。工具按深色横框识别区域；换图后如检测失败可调整阈值和覆盖率。生成结果为 `Assets/UnderAvatar/Resources/PaparazziComicCanvas.prefab`；可在 Inspector 的 `ComicPlayerUI` 上调整 `Fade Seconds`（默认 0.4 秒）、`Rise Distance`（默认 18）或替换分幕图片。重新生成会覆盖同名生成资源。场景的 `PrototypeApp > Paparazzi Comic Prefab` 可指定其他漫画预制体，留空则加载默认资源。

## 大笑探测、隐身与声音

正式对局中，主播按住 `Q` 探测（直播中也能用），狗仔按 `G` 隐身。狗仔的 `F` 仍用于打开手机。

- 大笑沿主播视角前方探测，锥角与视野灯一致，默认距离为灯光距离的 1.5 倍；穿墙显示狗仔红色轮廓，仅主播可见。停止探测后轮廓默认保留 3 秒；躲入床下或柜内立即隐藏轮廓。
- 大笑满条可用 5 秒，松开 Q 后每 2 秒恢复 1 秒额度，未回满也能使用；耗尽后需松开 Q 再恢复。
- 狗仔初始 2 次隐身，任务是否奖励隐身机会由任务编辑器单独配置，每次持续 10 秒，不叠加。隐身仍会产生正常移动声音，仍能被贴近抓捕；大笑可显出轮廓，但不会恢复实体模型。
- 屏幕下方居中显示红色技能图标、按键及进度条：主播 `Q 大笑`，狗仔 `G 隐身`，狗仔另显示 `B 假人` 次数。大笑条显示剩余额度，隐身期间显示剩余时长；搜捕计时圆环从顶部顺时针消减。
- 任务物体照片默认限 3 米，且受狗仔视野距离限制；手机任务界面显示有效距离。多目标任务的每个目标均需满足距离。可选的额外直播证据沿用原距离规则。
- 主菜单、漫画和教学大厅播放恐怖氛围 BGM，正式对局停止；漫画点击快进、翻幕和跳过均有翻页声。教学大厅开放拍照上传、隐身及大笑探测练习，隐身次数不限；不计分，不启动小游戏，也不触发胜负。

参数入口：`Tools > Under Avatar > Level Editor` → 玩法设置 → **大笑探测与隐身**，可调整距离倍率、轮廓时长、额度及恢复速度、初始隐身次数、隐身时长和任务拍摄距离；修改后保存场景（Ctrl+S）。联机由房主同步规则并判定技能，客机发送输入，不自行决定隐身次数或探测结果。

音频入口：`Tools > Under Avatar > Audio Settings`，可替换 BGM、漫画翻页声、大笑音效及调整各自音量。BGM 和翻页声使用 CC0 素材，来源见 `Assets/UnderAvatar/Audio/SOURCES.txt`；大笑使用用户提供文件转换出的 WAV，原文件保留。

协议升级为 **v16**，双方需使用同版本重新构建，不能与 v15 或更早版本混用。

## 大厅教学与手机地图

大厅左下角显示当前角色的练习步骤，完成后打勾；`H` 展开或收起。教学说明牌会朝向本机玩家，联机双方各自正确阅读；地图已移入手机。大厅仍没有小游戏、扣分、粉丝惩罚或胜负，双方准备后由房主开始正式对局。

狗仔在大厅按 `F` 打开手机，按 `Q` 进入相机，左键或空格拍照，再查看预览并点击“练习上传”；`Q` 打开／退出相机。收起手机后按 `G` 练习隐身，次数不限，右下角观察窗可以看到自己的模型消失和恢复。主播按住 `Q` 可探测门后的伙伴，床下和柜内除外；靠近电脑按 `E` 学习开播交互，靠近床或柜子按 `E` 练习搜查。

手机改为任务列表、滚动详情、结果提示、照片预览和固定操作按钮。长标题及长描述均可滚动阅读，上传按钮不会被文字挤走。成功显示绿色反馈并播放确认音，失败显示红色原因、剩余机会并播放失败音；仅错误上传扣一次机会，重复快照不重复播放反馈。`Audio Settings` 可替换成功／失败音效及调整音量。

按 `M` 直接打开手机地图，点击楼层按钮查看墙、门、楼梯、家具与主播电脑房；可缩放、滚动，没有实时玩家定位。M、F 或 Esc 收起手机，联机对方继续游戏。地图随关卡数据自动更新，不再生成或配置悬浮看板。

大厅主播使用独立的黑色神秘人替身，正式对局恢复恐怖奶龙。`Tools > Under Avatar > Character Models` 中可替换“教学大厅主播”预制体，或关闭“单人教学也使用大厅替身”。基础模型来自 Quaternius 的 Universal Base Characters（CC0），来源和许可保存在 `Assets/UnderAvatar/Art/Characters/Mystery`，带待机与行走动画。

默认搜捕时间从 30 秒延长至 **45 秒**，在 `Level Editor` 的“每轮搜捕时长”调整；小游戏通关分数沿用当前场景设置。

## 需求 5：手机地图、出生点、生命与空间音效

- **F** 打开／收起手机；手机桌面有「任务」「地图」两个图标。先在任务页选择目标，再按 **Q** 进入相机、左键拍照，确认后上传。上传或取消后收起手机；取消免费，错误上传仍只扣一次失误机会。
- **M** 直接打开手机地图，再按 M 收起。地图可切换全部楼层、缩放与滚动，显示房间、门、楼梯和主播电脑房，不显示玩家实时位置。关卡自动生成地图，不再生成悬浮看板。
- **出生点**：Unity 菜单 `Tools > Under Avatar > Level Editor`，找到「狗仔出生 / 复活点」，勾选自定义，设置楼层、网格 X/Z、朝向；也可在 Scene 中拖动绿色箭头。保存当前关卡资源。大厅与正式关卡各用自己的关卡资源，联机使用房主的关卡配置。未启用自定义时沿用自动出生点；出生点必须是空地且能到达电脑。
- **生命**：同一关卡编辑器中的「狗仔生命与复活」可调初始生命（默认 3）、死亡动画（默认 2.5 秒）、保护时长（默认 3 秒）。这些玩法设置保存在场景，修改后保存场景。被抓扣一命，前两次倒地、黑屏后回出生点；第三次在死亡动画后判主播获胜。保留任务进度与上传失误次数，清除未上传照片与隐身效果。手持道具优先放到面前有效表面；没有安全位置时回到它上次落地的位置。
- 保护期间可以移动，但不能被抓、拍照或上传。主播搜捕时间继续流逝。联机由房主扣命、计时与复活；复活会清除客户端的旧移动预测，迟到的上一条生命输入不会移动复活后的玩家。大厅仍没有生命损失或胜负机制。
- **声音**：`Tools > Under Avatar > Audio Settings` 中调「启用跨楼层衰减」「每隔一层音量倍率」（默认 0.45）和「相邻楼层低通频率」（默认 2500 Hz，越低越闷）。保留原有 3D 方位和距离衰减，脚步、门、快门、床、椅子、大笑均按本机听者所在楼层处理。BGM、手机反馈和本机喘气不受此衰减影响。保存音效配置资源即可。

联机协议升级为 **v16**，两台电脑需使用本次同一版本；旧 v15 包不兼容。当前死亡表现为程序控制的角色整体倒地与第一人称镜头动画。


## 需求 6：假人、直播规则与平面地图

- 狗仔 **B** 在原地放置固定姿势的假人，初始 1 次。假人可被声波探测；主播碰到后消失，搜捕／伏击阶段同时清空搜捕时间并进入返程。其他阶段只消除假人。大厅练习不消耗次数；正式对局的假人保留到被碰或本局结束，可同时放多个。
- `Tools > Under Avatar > Task Editor`：每项任务的「完成奖励」可选无奖励、隐身机会 +1、假人机会 +1，默认无奖励。重复上传不重复奖励。未绑定目标的草稿保留在资源中，正式对局跳过并提示；至少需要一个有效目标或开启额外直播证据。
- 主播 **按住 Q** 探测，**F / M** 打开仅有地图功能的手机。直播中禁止打开地图；搜捕、返程与大厅可查看。狗仔仍是 F 手机、Q 相机、M 地图。两者使用同一份浅底平面图，标出门、楼梯、床、柜、桌及电脑，不显示玩家实时位置，可切层、缩放和滚动。
- 每次开播粉丝恢复到配置的初始粉丝（默认 5000）。本场每次失败后目标分数减 1，默认最多减 4 分，最低 1 分；下场直播恢复该场原始目标。
- 返程中，电脑桌每隔 4 秒高亮 1 秒，只对主播显示。高亮使用声波轮廓方案；声波轮廓使用实际人物渲染，边缘向内绘制。
- 所有目标包含主播的任务，仅能在直播中拍摄，并与额外主播证据共用「每场最多一张有效主播照片」额度；取消有效主播照片也不会返还本场额度。任务界面自动注明。
- `Tools > Under Avatar > Level Editor` 的「狗仔生命与复活」可改初始生命数、死亡及保护时间；同一区域可改初始假人次数、每场失败降分上限、电脑高亮间隔及持续时长。玩法参数保存到场景；奖励保存到关卡资源。

## 2026-11-06：任务界面
